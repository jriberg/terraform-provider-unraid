# Unraid Provider

Manage an [Unraid](https://unraid.net) server as code through the official Unraid GraphQL API
(Unraid OS 7.x with the Unraid API / Connect plugin).

Works with Terraform and OpenTofu.

## Authentication

1. In the Unraid web UI, open **Settings → Management Access → API Keys** and create a key.
2. Give it the least privilege you need: the `VIEWER` role is enough for every data source.
   Each data source documents the resource/action it requires.
3. Configure the provider, preferably through environment variables:

```shell
export UNRAID_ENDPOINT="https://tower.local/graphql"
export UNRAID_API_KEY="..."
```

Use `https` where possible: the API key is sent as a request header.
For a self-signed certificate set `insecure_skip_verify = true` (not recommended).

## Example Usage

```terraform
terraform {
  required_providers {
    unraid = {
      source = "jriberg/unraid"
    }
  }
}

# Prefer UNRAID_ENDPOINT and UNRAID_API_KEY environment variables over hardcoding the key.
provider "unraid" {
  endpoint = "https://tower.local/graphql"
}
```

### Optional

- `endpoint` (String) Full URL of the GraphQL endpoint, e.g. `https://tower.local/graphql`. Can also be set with `UNRAID_ENDPOINT`.
- `insecure_skip_verify` (Boolean) Skip TLS certificate verification (for self-signed certificates). Defaults to `false`.

## Limitations

The provider only uses the Unraid GraphQL API. The API currently has no mutations for:

- creating or changing user shares (available read-only as `unraid_shares`),
- creating or configuring Docker containers or VMs,
- network settings and user accounts.

These remain web-UI-only until the Unraid API supports them.
